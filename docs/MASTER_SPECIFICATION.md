# GlobeTrotter – Master Specification

## Project Overview
GlobeTrotter is a personalized, intelligent, and collaborative multi-city travel planning platform.

## Key Frontend Modules (Dhanvi - Lead)
1. **Global Navigation & Layout**: Responsive header, user profile dropdown, active tab indicators, mobile navigation drawer.
2. **Authentication Flow**: Modal & standalone pages for Login, Signup, Forgot Password, and Guest/Demo switcher.
3. **Dashboard UI**:
   - Welcome banner with live user data.
   - Quick action cards (Plan New Trip, Explore, My Trips, Saved).
   - Upcoming trip countdown & active journey cards.
   - Total trips, saved destinations count, total budget tally.
   - Curated & recommended destinations grid.
4. **My Trips UI**:
   - Grid and list views with status filter tabs (All, Upcoming, Ongoing, Past, Public).
   - Search by destination or title.
   - Rich trip cards showing cover image, destination badge count, dates, budget progress.
   - Actions: View, Edit, Delete, Clone, Share.
5. **Create Trip UI**:
   - Clean, validated trip creation form with start & end dates, target budget, currency, description, and cover image picker.
   - Immediate redirect to trip details.
6. **Profile UI**:
   - Edit name, avatar photo, bio, home city, default currency, and preferred language.
   - Security controls and preferences.
